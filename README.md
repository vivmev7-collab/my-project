# Digital Product Sales & SEO Optimizer

This repository is dedicated to managing and optimizing the sales data for my digital storefront, **Pixel Templates**. I specialize in creating professional Canva templates and educational materials.

## Project Goal
The goal of this project is to build a suite of Python-based tools to:
- **Analyze Sales:** Calculate net profits after international platform fees (Etsy, Gumroad, etc.).
- **SEO Optimization:** Track and analyze keywords to improve product visibility.
- **Currency Conversion:** Automate price adjustments based on real-time exchange rates (SAR, SDG, USD).
